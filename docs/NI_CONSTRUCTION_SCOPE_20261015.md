# New Ithkuil construction: bounded grammar slice

**Private engineering evidence | 2026-10-15 | Source review d | No neural training**

## Executable result

`bilqis_mlx/ni_construction.py` implements two separate source-based grammars: stem-1/BSC numeral formatives for values 0 through 100, and single neutral-effect monadic referentials. Each has a constructor, an independent slot parser, explicit case selection, typed results, and official source URLs. Numeric input preserves the difference between Bilqis's exact scalar integer and the NI lexical root's set/cardinality reading. The old token IDs, graph, optimizer and trained student are never read or changed by this module.

For numerals, the compiler supports the thematic (THM) and partitive (PAR) cases and two morphological layouts: explicit Slot IV `a` plus default Slot VI `l`, or the Chapter 3.10 shortcut `w+a` in Slots I/II. The nine-degree `TNX` affix `-rs` is placed in Slot VII. For referentials, the current compiler supports the neutral-effect monadic `1m`, `2m`, `ma` and `mi` forms with THM, ERG, ABS and INS cases.

This is an intentionally narrow subset. A rejected construction is **outside this implementation's supported grammar**, not necessarily ungrammatical in New Ithkuil.

## Exact sources and semantic limits

- [Official numbers, §13.2 and §13.4](https://ithkuil.net/newithkuil_13_numbers.htm): numerical roots, TNX degrees and spoken numeral examples. Stem-1 BSC numerical roots represent sets/cardinality, not unqualified mathematical scalar literals.
- [Morphology, §3.10](https://ithkuil.net/newithkuil_03_morphology.htm): shortcut `w+a` substitutes the default Slot IV and Slot VI morphology.
- [Morphophonology, §2.3](https://ithkuil.net/newithkuil_02_morpho-phonology.htm): fixed formative slot ordering. This version implements no arbitrary Slot V, VIII, concatenation, or dynamic wordform stress.
- [Cases, §4.2.1 and §4.3.9](https://ithkuil.net/newithkuil_04_case.htm): THM `-a` and PAR `-ui`. Other nominal cases are intentionally excluded from the numeral interface.
- [Referentials, §9.1](https://ithkuil.net/newithkuil_09_referentials.htm): consonantal neutral monadic referents and case vowels. These are not Bilqis's independently named `A..E`, `J0..J2`, or event IDs.

The parser requires explicit cases. The grammar's full multiword number constructions sometimes omit or modify a case marking in their wider morphosyntactic context. Such whole-number phrases, optional special roots for 11 through 15, complex proper-name carrier forms, dual referentials, affix stacking, stress, allophonic changes, phonotactic repairs, and full NI morphological legality are **not implemented**.

Formal truth functions, finite Horn-closure entailment, Belnap-style evidence and set/function operators stay as typed Bilqis formal adapters. No direct NI lexical equivalence is inferred from this compositor.

## Operator commands

Run the bounded compiler directly:

```sh
python3 -m bilqis_mlx.ni_construction number 42
python3 -m bilqis_mlx.ni_construction number 21 --shortcut
python3 -m bilqis_mlx.ni_construction number 100 --case PAR
python3 -m bilqis_mlx.ni_construction parse-number wallärsa
python3 -m bilqis_mlx.ni_construction referent 1m --case ERG
python3 -m bilqis_mlx.ni_construction parse-referent lo
python3 -m unittest tests.test_ni_construction -v
npm run test
npm run train -- --dry-run
```

Each successful command returns or tests source-linked analyses; none admits new lexical tokens or updates the student. The original model remains pinned to `legacy-source/v1`; the semantic review is `mapping-review/20261015-d`.
