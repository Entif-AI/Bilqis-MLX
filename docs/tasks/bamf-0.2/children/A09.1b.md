# A09.1b | Reconcile qualified source, learning, correction and policy events without mutation

**Status:** BAMF-0.2 implementation work packet; **lane:** A / [#342](https://github.com/Entif-AI/Bilqis-MLX/issues/342). **Ancestor:** [A09 #360](https://github.com/Entif-AI/Bilqis-MLX/issues/360). **Direct parent:** [A09.1 #389](https://github.com/Entif-AI/Bilqis-MLX/issues/389). **Kind:** leaf.

## Concrete bounded outcome
Implement reconcile(snapshot, qualified_event) as a pure, deterministic fold that returns a fresh immutable snapshot only for an authorized, typed, versioned event. Support qualified source release/rights changes, real learning or retained-assessment evidence, correction/invalidation, explicitly accepted Factory admission, and versioned planner/teacher policy changes. Validate event identity, source provenance and generation predecessor before applying. Preserve earlier snapshots and held/uncovered obligations; new source releases create a new coverage epoch rather than resetting old identity or silently admitting new rights. A rejected or duplicate event cannot advance a cursor, learner mastery, debt or admitted release. This is snapshot transformation only; C07 owns atomic lease/admission and the runtime event publisher.

## Precise inputs and existing owners
Versioned CurriculumSnapshot from A09.1a and source/learner/Factory/policy events with existing provenance and accepted/rejected disposition.

**Direct work prerequisites:** [A09.1a #390](https://github.com/Entif-AI/Bilqis-MLX/issues/390). The parent A09 also depends on A08 #358. Existing #296 Factory/adoption remains the staging owner. A missing dependency commit can be represented by a frozen interface fixture during coding; final integration must use its actual receipt.

## Output contract
reconcile(snapshot, qualified_event) -> CurriculumSnapshot (or typed rejection/status), with deterministic next-generation digest and explicit change set for replan.

## Completion/acceptance owned by this packet
The same event applied to equivalent snapshots has equal output; replaying the same event is idempotent. A correction invalidates only dependent coverage/evidence and never rewrites historical state. Source release growth retains older IDs and carried debt. An unqualified or mismatched release/lease event is rejected rather than fabricating eligibility or learning. Changed accepted evidence provokes a new snapshot; no change returns the original state/fixed-point disposition.

## Boundaries and non-owned work
