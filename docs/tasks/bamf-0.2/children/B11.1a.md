# B11.1a | Produce execution-owned backbone group-boundary receipts

**Program:** BAMF-0.2 root #341. **Lane:** B. **Parent:** B11.1 #471 / B11 #369. **Originating blocker:** B05.4 #577 / draft PR #584.

## Outcome
Create the smallest real atlas-native backbone producer that owns computation of h0 and completed group-4/8/12 hidden states and emits the only production provenance accepted by B05 depth selection.

This issue exists because B05 cannot authenticate the origin of arbitrary caller-provided tensors. `AttentionScope`/`AttentionCache` prove cache consistency relative to caller-bound generation/prefix coordinates; they do not attest that a tensor was actually produced by the BAMF backbone at the declared group boundary. Process-local tokens, Python object identity, caller-supplied labels, or hashes of caller-supplied hidden bytes are not sufficient producer provenance.

## Dependency-cycle rule
This child is deliberately carved out of B11.1 so it can precede B05 parent acceptance. It consumes the accepted B01 topology/parameter registry, reviewed B04 attention/block primitives, and the already-implemented B05 numerical selector contract as a downstream numerical operation. It **must not depend on B05.4 provenance acceptance** or B13 final generation custody. Full B11.1 remains responsible for complete model assembly after the surrounding owners are accepted.

## Required producer boundary
Expose an execution-owned API whose production entry point accepts authoritative model inputs/parameter state and **computes** the hidden states it attests. Production receipt construction must not accept an arbitrary `h0`, `g1`, `g2`, or `g3` tensor from its caller.

The producer receipt must bind, from values observed/derived by the producer itself:
- B01 topology/parameter registry identity;
- deterministic content identity of the actual parameter tree used for execution, not object identity and not extents alone;
- semantic/input generation binding available at the execution boundary;
- prediction/input-prefix boundary and actual B04 attention/cache scope chain consumed by the executed blocks;
- exact completed group/layer boundary;
- ordered predecessor source identities/digests used by the depth selector;
- digest/shape/dtype of the hidden state actually returned by the executed group;
- the boundary-transform disposition immediately before capture, including the declared group-1 motif-read position. A fail-closed/no-hit motif disposition may be represented honestly during upstream B08 quarantine; it may not be represented as an authorized hit.

The API may retain private numerical helpers for tests, but B05's production path must consume only output produced by this execution-owned path.

## Acceptance
1. Execute a literal BAMF group-1 path from an authoritative h0/input state through the real B04 blocks; capture the resulting group-4 state through the producer, then select it through B05.
2. Continue the same producer chain through group 2 and group 3 using the preceding selected state; receipt ordering is h0,g1,g2,g3 and future groups are absent.
3. The reproduced g2-as-g1 attack cannot be expressed through the production producer API. A test-only attempt to pass arbitrary g2 bytes as g1 is rejected before B05 selection.
4. Two distinct B01-compatible parameter trees with identical extents produce distinct execution/parameter identities and cannot reuse one another's group receipts.
5. Changing generation/input prefix/B04 cache chain/group index/parameter content changes or invalidates the receipt before selector computation.
6. No secret global token, Python object identity, caller-supplied `generation` string, or caller-computed hidden digest is accepted as sole proof of producer origin.
7. Gradients from B05 selection flow through the actual produced group state back into the executed backbone parameters.
8. B05.4 #577 reruns its adversarial negative witnesses against this exact producer and removes the public fail-closed hold only after fresh independent EGM finds zero Blockers/Majors.
9. Full B11.1 later reuses this producer contract rather than creating a second depth-summary authority.

## Scope / non-goals
This is a producer-authenticity and execution-boundary leaf. It does not complete the 12-layer model, B08 source authority, B12 optimizer custody, B13 retained-generation publication, or live training. It must not weaken the current fail-closed B05.4 public path while this issue is incomplete.

Fresh independent EGM is required before integration.
