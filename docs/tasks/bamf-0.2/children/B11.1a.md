completed-group receipt only from that executed path. The receipt must
bind the actual input and output tensors to the model generation,
prediction prefix, implementation, parameter tree, source rights,
group/layer interval and predecessor chain.

The public B05 selector must not accept arbitrary arrays plus matching
metadata. A caller cannot relabel g2 bytes as g1, reuse another model

Group 1 must record the second motif-read boundary after layer 4
and before capture. Until B08 authority is admitted, the disposition
must be an explicit fail-closed/no-hit, never a fabricated authorized
hit. Group 2 and group 3 must preserve the exact source order
h0, g1, g2, g3. The eventual B11 full forward consumes the producer;
it does not become a prerequisite for the producer itself.

## Execution boundary

The first bounded implementation unit is the fixed four-layer numerical
forward. It uses B01 parameter names and shapes, B04 CCGQA, pre-RMSNorm,
squared-ReLU FFN and residuals. Its result is explicitly **unadmitted**.
It does not mint a producer credential, and B05 must reject it.

The second unit binds B03 source-approved h0, actual parameter-tree
content digest, execution generation/prediction prefix, B04 cache
scope chain, B08 motif-read boundary/disposition and the executed
tensor chain. B13 final retained-generation custody remains separate.
Only the fixed executed producer may issue a trusted receipt.
Do not substitute a private constructor token or a caller-supplied
digest for executed source provenance.
