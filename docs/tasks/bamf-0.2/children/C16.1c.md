## Exact owned result

Implement the smallest host-owned handoff that makes generation-zero custody capable of carrying lawful C09 source-authority trust without caller selection:

1. Establish the source-authority registry through a host-owned authority surface outside package/CLI choice. No public/caller registry constructor or first-writer-wins file placement may grant live authority.
2. Bind the exact registry record/digest into generation-zero accepted custody at the B13 genesis boundary, under the same accepted run identity and atomic publication contract.
3. Ensure `AcceptedRuntimeHost(run_dir).source_authority()` can mint/reuse the opaque `SourceAuthorityRuntime` from that accepted generation-zero binding without reading a raw caller registry.
4. Preserve #917 fail-closed behavior for raw registry input, copied host files without custody binding, caller construction, exact-type forgery, foreign capabilities and stale/wrong-scope/wrong-key authority.
5. Preserve #926/#904 generation-zero authentication, retry/idempotence and immutable trust-root semantics. The new binding must not make generic package/data-plane writers capable of minting or replacing the host trust root.
6. Expose only the owner-consumable authority required by C07 persistence. This leaf does **not** parse CLI flags, select an admission scope, issue a lease, adopt a successor, or start neural training.
7. Failure is atomic: if host authority cannot be established or bound, no new accepted pointer, partial C09 binding, C07 lease, optimizer mutation or learner update may remain.
