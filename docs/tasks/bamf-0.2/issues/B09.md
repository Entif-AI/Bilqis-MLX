## Implementation prescription
Add three rank8 adapters at group boundaries. Zero B matrices make initial adapters identity. FAST includes adapters, motif parameters and newly activated semantic rows; SLOW includes established embeddings and dense parameters. A new row becomes established after eight accepted updates that actually touched it. FOUNDATION updates the full tree. ADAPTIVE offers FAST candidates, then FULL after eight accepted FAST candidates; the existing teacher can request FULL earlier for foundational remediation. This policy selects update eligibility, while the teacher still selects targets, learning rate and pedagogy. Persist mode, counters, row ages and policy version. Advance clocks by accepted updates rather than wall time. Inference always consumes both groups. Freeze the update mask at candidate preparation. B12 owns optimizer moments and update counts.

## Relevant shared contracts

### Plastic

FAST group contains adapters, motif vectors/projections/gates and newly activated identity rows; SLOW contains established embeddings and dense/core parameters. Foundation mode updates all groups. Adaptive mode updates FAST each candidate and offers a FULL candidate after8 accepted FAST candidates, or when the existing teacher requests foundational remediation. Rejection leaves both clocks and all state at the retained parent. Keep native AdamW arithmetic and selected hyperparameters; the optimizer owner maintains per-parameter update counts so inactive/new parameters receive correct bias correction. The cadence policy is explicit versioned data; no learned meta-optimizer is required for delivery.
