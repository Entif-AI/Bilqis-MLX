receipts while making their exact source identity mandatory. `_receipts` now
preserves implementation receipts as `(number, source_id)` pairs; the A05.5 and
A08.1b.5 special parsers require the exact expected pair in addition to the
already-pinned source digest. A same-number alternate PR source therefore cannot
borrow the expected digest from a different source record.

generic grammar. The regression suite now uses syntactically valid alternate PR

special-parser semantics, and the verified final graph result.
