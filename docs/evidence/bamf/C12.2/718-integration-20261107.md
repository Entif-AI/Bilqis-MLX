## Authority chain

The production entry point is
`cognitive_package.operator.receive_screen_and_publish_package(...)`.
It composes existing owners in this order:

1. C12 derives the receiver binding from the current B13 generation and receives one
   bounded local package through `receive_package(...)`.
2. A12/C09 verifies the signed `ExportClearanceReceipt` against the current Atlas
   selection, source frontier, owner-bound C09 source authority, exact artifact set,
   rights epoch, correction generation, and receiver correction frontier.
3. B12 creates the package-import transaction from the current accepted parent. The
   fixed reset policy changes only declared slices and resets the owned optimizer
   state for those slices without importing sender optimizer state.
4. C05 evaluates the B12 transaction through `evaluate_factory_package_import(...)`
   and issues the retention decision. The caller cannot supply policy, cohorts,
   evidence, or an acceptance Boolean.
5. C12 re-reads the current parent and A12/C09 authority before B13 publication.
   B13 mints the acceptance binding from the owner-issued C05 decision and records a
   `PACKAGE_IMPORT` generation transition.

`SourceRights` remains a portable projection. Matching package-local fields do not
authorize export or publication. C05 eligibility also does not publish a generation.

## Security correction after parent review

The first parent checkpoint `e727641a7721ca21a6ed88d00ffb7f2da37be924`
exposed one Major before turn-in: C12 accepted a caller-selected
`SourceAuthorityRegistry`. Because that registry is a portable public record, a caller
could generate its own Ed25519 key, sign a matching `ExportClearanceReceipt`, and make
the supplied registry its own C09 trust root. The first EGM target was therefore marked
obsolete/superseded and is not review evidence.

Semantic repair head `291a283f80c750b7ae81750ba692d9a47e5f0fca` removes the raw registry
from the C12 boundary. `SourceAuthorityRuntime` is now an opaque process-local C09
capability. Its constructor rejects callers, exact-type forgeries fail the owner lookup,
and `publish_screened_delta_import(...)` and the aggregate operator accept only that
capability. The raw registry stays hidden behind the capability's A12 validation method.

The repair was test-first. On the pre-repair code, the new public-boundary adversary
failed as expected because `authority_registry=` was still accepted:
