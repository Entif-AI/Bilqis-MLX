## Problem, goals and non-goals

The useful-learning qualification in public issue #1645 / IPR-0220 has repeatedly
observed zero retained steps. Its immediate question is whether source-bound
learning directions, native AdamW displacement and actual ordinary instruction
explain a measurable obstacle. The diagnostic estimates one-step effects, not
the probability of a successful visit or the ability of the architecture to
master all six Grade A capabilities. The broader issue remains open until its actual matched native qualification,
independent fixed examination, measured outcomes, evidence and follow-up owner
obligations are satisfied. Improving independent acquisition and delayed retention
per wall-clock minute is the research objective, not an invented issue-closing
threshold. Negative outcomes remain valid evidence.

Deliver a reproducible, isolated comparison of six capability-specific
gradients, the actual native optimizer displacement, and separately drawn
protected losses. Compare the normal selected lesson when the native selector
permits one. Preserve honest missing observations, especially candidate-evaluation
invocations, the historical execution identity, and R4's 25/72 independent
assessment coverage. Do not change C05, production strategy, the source catalog,
champion authority, assessment law, or the sovereign model and its own AdamW.

## Alternatives considered

* Raw gradient cosine alone is cheap, but it omits the accumulated moments,
  participation masks, per-leaf clocks, preconditioning and decay. Native
  displacement is the appropriate intervention coordinate. Retain the raw
  cosine as a comparison, not as the adjudicator.
* A purely analytic AdamW approximation is cheap, but it cannot establish the
  actual finite effect or account for native numerical details. Use native
  displacement and forward-only replay as the reference; keep analytic terms
  for attribution. Reusing the saved displacement avoids repeating gradients.
* A forced homogeneous synthetic lesson would provide broad coverage but hide
  lawful native holds, source delivery and mixed rehearsal. Use controlled draws
  for coverage and a separate natural ordinary lesson for actual delivery.
* Running whole candidate visits with changed policy or resetting optimizer
  history would confound diagnosis, consume additional compute and require a new
  operator decision. Defer those comparisons to the subsequent bounded,
  matched experimental unit. An output-only epsilon change is not established
  as a remedy by its counterfactual direction.
* Prefer full authenticated cadence replay when complete historical objects are
  available. When an object is genuinely missing, use only a prior trusted
  operator-authorized freeze with the exact projection, originating indexed
  prefix and accepted anchor, followed by the native unseen-tail check. A
  fabricated event or an arbitrary mutually consistent projection/database
  pair cannot replace missing historical authority.

## Risks, limits and failure handling

The trusted freeze is an explicit operator input, not proof from path names.
Validate projection bytes, exact accepted pointer, schema/anchor, contiguous
ledger prefix, every indexed record's canonical payload and content identity,
and originating projection/index identity. Rebind only to the disposable
namespace and authenticate the unseen tail using the native cadence owner.
Abort on ambiguity or mismatch. The design's trust precondition is not a
general sovereign recovery mechanism. A review finding about executable
enforcement of the trusted input must be resolved before accepting a new
implementation; no claim that a matching caller-generated database proves
authenticity.

Bound each native process at 12 GiB MLX (the controlled CLI may explicitly use
16 GiB), cache limit zero, `BILQIS_TEST_WORKERS=1`, one neural lane and a
two-hour absolute verification ceiling. Use the immutable detached source
snapshot runner for commands plausibly over five minutes. No duplicate launch
or polling. Inspect real host pressure before expensive work and preserve
terminal failure receipts. CPU-only matrix processing is distinct from MLX
allocation. The observed native, mixed and finite witnesses took 212.507,
83.550 and 129.299 seconds respectively; these describe the existing evidence,
not production throughput or guaranteed future runtime.

Historical target-only C05 decisions censor peer/protected outcomes; do not
assign unobserved pass/fail. Distinguish within-capability separate-draw loss
increases, cross-capability interference, and actual joint attainability.
Report attempted optimizer steps, terminal decisions, selection calls, actual
evaluation invocations/latency and independently retained competence as separate
denominators. Missing historical denominators remain unavailable. Preserve the
existing source result digests and the original terminal receipts; never
retroactively label historical draws as independently issued exams.

## Concrete remediation contract and verification plan

This section controls any less-specific wording above. All three independent
review reports concern the original target, not a passing amended design.

### Shared basis and immutable probe identity (M1, M2, S4, C3)

* `authentic_dynamics.source_gradient` aggregates row gradients by union of
  parameter names, using a zero contribution only for an omitted leaf whose
  B09 mask for that row is entirely frozen and participation is `(False, ())`.
  Reject foreign names, shape drift, nonfinite loss or gradient; use the same
  authenticated parent parameters and optimizer for every arm. Factory source
  draw seed is deterministic; no independent stochastic-RNG equivalence claim
  is made. Each of N compiled rows contributes 1/N to the mean source loss and
  gradient. Derive aggregate B09 participation from the actual executions.
* Extend only proven frozen omissions to zero for the saved protected probe;
  retain the native sparse target tree for AdamW. Record omitted protected
  leaves and exact parent shapes in the receipt. Persist a common protected
  probe set per result, reused for every target arm. Record source-family and
  episode overlap between target and protected draws, not independence.
* `displacement_analysis.interference_matrix` requires explicit parent-basis
  name/shape mapping. Validate the complete protected key sets and the complete
  expected update key sets (raw, clipped, delta, old_moment, decay, mask, and
  designated epsilon variants); validate vector shape and finiteness; never
  infer the basis from a probe. Empty target set is a lawful unavailable mixed
  matrix. Zero-norm raw cosine is null; dot is signed protected gradient times
  actual after-minus-before displacement, positive predicts harmful loss.
* Native delta includes clipping, selected clocks, moments and decoupled decay.
  The old-moment contribution uses the actual next second moment denominator
  and clock. Current-gradient plus rounding is the remainder, not an exact
  nonlinear attribution. Second-moment variants hold first moment, gradient,
  clock and decay fixed, match adaptive direction norm where defined, and
  do not mutate optimizer state. A zero norm gives no direction; a large finite
  residual limits linear interpretation rather than invalidating custody.
  Finite replay is 36 baseline and 216 displaced rows at the six-by-six default,
  one native displacement at a time from the same accepted parent; residual
  is observed minus predicted. Existing numeric tolerances above apply to
  the observed dtype and are not thresholds for future learning.

### Freeze admission (M3, S3, C2, C4)

`cadence_custody.verified_projection` requires an independently supplied
expected digest of a freeze manifest, not a caller root alone. The manifest
schema binds original capture receipt SHA-256, frozen pointer SHA-256,
projection SHA-256, exact ledger byte frontier and SHA-256, frozen SQLite DB

require no nonempty WAL, verify frozen file bytes against these pins before
reading and DB identity again after validation, and reject symlinks. The
operator's independently held authorized manifest identity is the trust input;
internal consistency or a freshly minted matching pair is not authenticity.
The existing #1657 frozen evidence is admissible only through its previously
recorded projection/prefix/anchor and actual origin receipt, plus a clearly
labeled present-byte audit manifest. Its failed initial execution receipt is
not a successful training or freeze proof; no historical authority fabricated.
Require sequence 1..N in order, byte start equals previous end, exactly one
indexed record per complete ledger line; distinct repeated event IDs at
separate offsets are not rejected merely for equality. Match canonical event
payload/digest and exact projection/index identity. Validate target prefix and
pointer again before rebinding via native `_seed_cadence_projection`, then
native unseen-tail authentication. No source writes; fail closed before
rebind for missing pin, paired forgery, duplicate/gap/out-of-order sequence,
truncation or ambiguous authority. `--cadence-freeze-manifest` and
`--cadence-freeze-sha256` required together with projection root. Full native
replay remains the alternative. An unavailable historical object remains
unavailable, never generated. Only disposable destinations may be rebound.
