# Source roles

`source_manifest.csv` records the exact local research snapshot used to build the CSVs.

The official New Ithkuil website and linked lexicon are primary linguistic evidence. The Bilqis Curriculum Registry is a separate enrichment source and never overrides an explicit grammar/lexicon distinction.

Raw fetched source files live under ignored `lib/ithkuil/_raw/`. The workbook export lives outside Git. Derived rows cite their source loci so another run can reproduce or audit the extraction.
