# Full-corpus clean-room rebuild (#93)

This proof covers the current admitted source/compiler scope. Held rows and
unparsed frontier debt remain explicit. It does not perform graph materialization,
curriculum admission, neural training, merge or release publication.

Use the exact candidate recorded in `evidence/release-93.json`. Keep all code and
Python execution local. No graph service is required. Start each run from a
separate `git archive` of that revision, without copying ignored local files:

```sh
git -C <repository> archive <candidate-sha> | tar -xf - -C <new-runtime-directory>
```

The tracked source manifests, chapter PDFs, profiles, code and reviewed mapping
inputs come from that candidate. Tracked CSV baselines also support the source
owners' existing compatibility checks. They are not a substitute for missing raw
sources: the canonical source action verifies every raw pin before rebuilding.
All source-owned tables are regenerated by their canonical owners. Preserve the
reviewed mapping/bridge inputs; this gate does not invent source facts for them.

Create a fresh virtual environment and install the selected candidate's
`requirements-extraction.txt` and `requirements-semantic.txt` with pip's
`--no-cache-dir`. Record Python/OS/architecture and `pip freeze --all`. Do not
install neural, model-provider or graph clients merely for this proof.

In each new runtime, independently restore every row of
`lib/ithkuil/_data/csv/sources/source_manifest.csv` from its declared URL into
`lib/ithkuil/_raw/<local_name>`. Use the existing `fetch_sources.fetch` transport
helper, or trusted curl with a finite timeout. Download only into new files in that runtime's ignored raw directory.
Verify every SHA-256 and byte count against the unchanged manifest before invoking
the source action; a mismatch blocks the run. Record URL, source ID,
expected/observed hashes and byte counts. Do not invoke `fetch_sources.main`,
rewrite a pin, copy an existing raw cache, or replace an unavailable source with
old generated CSVs.

Run from that selected runtime, using the fresh environment's interpreter:

```sh
<python> -B -m lib.ithkuil.src.ingestion \
  --repo <runtime> --python <python> --selection all > <source-result.json>
```

  --frontier <runtime>/lib/ithkuil/_data/csv/sources/extraction_frontier.json \
  --source-result <source-result.json> --output-root <new-semantic-output> \

canonical RDF/digest/held ledger separately from the full-domain conformance
